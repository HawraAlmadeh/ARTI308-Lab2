--------Problem Description--------
Classification problem, Detecting credit card fraudulent transactions using a set of well chosen feature to train the model to predict whether a transaction is fraudulent or legitimate.


--------Dataset Description--------
The dataset is from Kaggle. It contains 10,000 records of financial transactions. It has 11 features including target variables like (is_fruad and Risk_Score).

 (link: https://www.kaggle.com/datasets/greatcool/financial-transactions-and-fraud-detection-dataset)
